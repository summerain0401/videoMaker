# 选题需求

## 频道定位

面向普通人的通俗财经与消费决策长视频。用生活化场景、行为心理和反直觉案例解释金钱决策，最终落到可执行的方法；避免把内容做成投资荐书或成功学口号。

## 目标受众

- 对收入、储蓄、投资与消费感到焦虑的普通职场人。
- 希望建立长期财富观，但没有金融专业背景的观众。
- 看完后应能识别金钱决策中的情绪与认知陷阱，并形成一项可执行的长期习惯。

## 希望解决的问题

围绕摩根·豪泽尔的《金钱心理学》，解释财富结果为何常由行为、耐心、风险承受能力和个人经历塑造，而不仅是知识或智商。选题必须兼具强钩子、清晰机制、生活案例和可执行的自检方法。

topic 阶段只为这一本书提出 3 个不同切入角度，不得更换书目。三个候选应在核心问题、受众承诺和视频标题上形成明显差异。

## 排除方向

- 不提供股票、基金、加密资产或其他具体投资建议。
- 不使用无法核验的收益数字、人物故事或夸张财富承诺。
- 不涉及政治争议或敏感议题。
- 不大段复述原书，不引用受版权保护的长段原文。
- 不把节俭或冒险当作唯一正确答案，应强调个人目标与可承受风险的匹配。

## 候选书池（可选）

- 《金钱心理学》｜摩根·豪泽尔｜书单分类：财富行为与长期决策｜方向：金钱选择背后的行为逻辑。
