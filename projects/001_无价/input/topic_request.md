# 选题需求

## 频道定位

面向普通人的通俗财经与消费决策长视频。用生活化场景、行为实验和反直觉案例解释经济与商业机制，最终落到可执行的方法；避免把内容做成投资荐书或成功学口号。

## 目标受众

- 希望减少冲动消费、看懂价格套路的普通消费者与职场人。
- 对财经、行为经济学感兴趣，但没有专业经济学背景。
- 看完后应能识别锚定、诱饵和参照价格，并在购物或谈判前进行自检。

## 希望解决的问题

围绕威廉·庞德斯通的《无价》，解释价格为什么并非客观数字，以及商家如何利用锚定效应、诱饵选项、参照价格等心理机制影响人的支付意愿。选题必须兼具强钩子、清晰机制、生活案例和可执行的消费检查方法。

topic 阶段只为这一本书提出 3 个不同切入角度，不得更换书目。三个候选应在核心问题、受众承诺和视频标题上形成明显差异。

## 排除方向

- 不提供股票、基金、加密资产或其他投资建议。
- 不使用无法核验的实验数字、人物故事或夸张财富承诺。
- 不涉及政治争议或敏感议题。
- 不大段复述原书，不引用受版权保护的长段原文。
- 不把“高价一定是骗局”作为预设结论，应区分心理定价与真实品质差异。

## 候选书池（可选）

- 《无价》｜威廉·庞德斯通｜书单分类：消费心理与营销经济｜方向：价格背后的心理游戏。
