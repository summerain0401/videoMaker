# 选题需求

## 书目

《百万富翁快车道》

## 作者

MJ·德马科

## 核心痛点

为什么很多人勤奋工作、节衣缩食，却始终只是在“慢车道”上前进；怎样识别以时间换钱、
消费主义和高杠杆承诺带来的假富裕，并建立可复制、可规模化的财富路径。

## 目标受众

25–45 岁有收入焦虑的职场人、自由职业者、创业初期人群与长期学习者；希望提升收入与
选择权，但不希望被暴富神话或高风险投机误导。

## 视频标题（可选）

为什么越努力上班，离自由越远？《百万富翁快车道》讲透财富积累的底层路径

## 素材要点

- 三条财富道路：人行道、慢车道、快车道；重点解释它们的思维方式与风险差异。
- 反对把“高消费 + 高收入”误当成富裕，也不鼓吹借贷、投机或一夜暴富。
- 快车道的核心不是捷径，而是为真实需求创造价值，并让价值可以复制、规模化、脱离单次出卖时间。
- 保留普通人可执行的行动：识别问题、积累技能、验证需求、控制风险、长期复盘。
- 明确边界：本片为原创读书解读与通俗教育，不构成投资、创业或借贷建议。

## 结构与篇幅

五段式（开场共情 / 底层病灶 / 核心模型 / 实战工具 / 哲学升华），
口播总字数 3800–4500 字，成片约 13–18 分钟。

## 风格

口语化短句、痛点引导、二元对立概念、每 3–4 分钟金句；既要拆穿“慢车道”的误区，
也要避免制造焦虑或鼓励冒险，结尾用灵魂提问引导互动。
