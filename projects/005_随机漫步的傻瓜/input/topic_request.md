# 选题需求

## 频道定位

沿用 004 的频道定位：面向普通人的通俗财经与消费决策长视频，用生活化场景、行为心理和反直觉案例解释金钱决策，最终落到可执行的方法；本期显著区别前四期，减少“省钱/习惯/消费技巧”叙事，转向概率、运气与决策质量的认知观察。

## 目标受众

- 对收入、职场、创业和个人选择中的“成功与失败”感到困惑的普通职场人。
- 容易把一次结果、他人的成功故事或幸存者经验误认为稳定能力的人。
- 看完后能区分运气与能力，关注过程决策，并建立基本的风险意识。

## 希望解决的问题

围绕纳西姆·尼古拉斯·塔勒布的《随机漫步的傻瓜》，用生活化案例解释：我们为什么会把运气误认成实力、把幸存者当成榜样，以及如何用过程而非单次结果评价决策。topic 阶段仅输出 3 个彼此明显不同的切入角度；三个候选须在核心问题、受众承诺和视频标题上形成差异。内容聚焦运气、幸存者偏差、过程决策和风险，不提供投资建议。

## 排除方向

- 不提供股票、基金、加密资产或其他具体投资建议。
- 不把书中观点包装成收益承诺、致富方法或投资荐书。
- 不使用无法核验的收益数字、人物故事或夸张成功案例。
- 不大段复述原书，不引用受版权保护的长段原文。
- 不把成功简单归因于能力，也不把失败简单归因于个人缺陷；强调概率、信息局限和可承受风险。
- 不延续前四期以节俭、储蓄、消费技巧或习惯养成为主的切入方式。

## 候选书池（可选）

- 《随机漫步的傻瓜》｜纳西姆·尼古拉斯·塔勒布｜书单分类：概率思维与风险决策｜方向：运气、幸存者偏差、过程决策与风险。
