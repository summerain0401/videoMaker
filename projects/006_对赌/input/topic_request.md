# 选题需求

## 频道定位

沿用本频道面向普通人的通俗财经与消费决策长视频定位：用生活化场景、行为心理和反直觉案例解释金钱与人生中的决策，最终落到可执行的方法。本期承接 005《随机漫步的傻瓜》对运气与结果的讨论，但转向信息不足时的日常决策方法。

## 目标受众

- 在跳槽、副业、消费、人际与人生选择中，常因不确定而拖延或事后自责的普通职场人。
- 容易用单次成败判断自己或他人能力，并把坏结果等同于坏决定的人。
- 看完后能区分“决策质量”和“结果好坏”，学会用概率与复盘改善选择的人。

## 希望解决的问题

围绕安妮·杜克的《对赌：信息不足时如何做出高明决策》，解释为什么好决定也可能有坏结果、坏决定也会偶然成功，以及普通人如何在信息不全时评估把握度、设定可承受损失并复盘过程。topic 阶段仅输出 3 个彼此明显不同的切入角度；三个候选须在核心问题、受众承诺和视频标题上形成差异。

## 排除方向

- 不提供股票、基金、加密资产或其他具体投资建议。
- 不把“对赌”包装成赌博技巧、收益承诺或投机鼓励。
- 不使用无法核验的收益数字、人物故事或夸张成功案例。
- 不大段复述原书，不引用受版权保护的长段原文。
- 不将概率思维误解为逃避责任；强调在不确定中提高决策质量，而非追求绝对正确。
- 不重复 005 对运气、幸存者偏差的书评式讲述，应以“如何在信息不足时行动”为主要落点。

## 候选书池（可选）

- 《对赌：信息不足时如何做出高明决策》｜安妮·杜克｜书单分类：决策科学与概率思维｜方向：不确定性、过程复盘与更好的日常选择。
