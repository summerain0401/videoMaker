# 长视频制作工作流（项目制）

本仓库只做 16:9 听书解读长视频。每个项目一个目录（`projects/001_金钱的艺术`、
`projects/002_…`），内部按「输入 / 中间产物 / 产出」分层，脚本按 `PROJECT`
环境变量（默认 `001`，`--project` 可覆盖）自动解析路径。

## 项目目录结构

```
projects/001_金钱的艺术/
├── project.json    # 元数据（id/title/author/status）
├── input/          # brief.md、script.txt(.bak)、draft_*.txt、storyboard_narrative.json
├── assets/         # scenes/（卡点画面）、art/（历史底图存档）、layers/（渲染中间层）
├── audio/          # voice/（配音缓存）、music.wav（背景乐）、tmp/（合成中间）
└── output/         # 成片 mp4、long_summary.json、storyboard_long.csv、preview/（抽帧）
```

新建项目：先建 `projects/002_书名/`（脚本未找到时也会自动创建
`projects/{id}_新项目`，可随后改名，匹配只看数字前缀）。

## 默认工作流：Codex 原生制作（无 API）

在 Codex 中调用 `$video-maker-production` 启动或恢复任务。技能会使用内置文本能力与
ImageGen，所有模型生成均在 Codex 中发生；`pipeline/codex_jobs.py` 只处理本地状态、
候选目录、校验与人工确认后的提升，不读取 API 密钥也不访问网络。

```bash
# 创建 run；将输出候选文案、候选 JSON、候选图片和状态文件路径
python3 pipeline/codex_jobs.py init

# 中断后用 run_id 恢复；生成图片前先只列出少量试点拍
python3 pipeline/codex_jobs.py status <run_id>
python3 pipeline/codex_jobs.py image-targets <run_id> --beats 00_0 00_1
```

阶段顺序固定为：候选文案校验 → 人工确认定稿 → 候选分镜校验 → 人工确认提升 →
候选图片校验与抽查 → 人工确认提升。`promote` 默认不覆盖已有正式资产；需要重绘时必须
显式使用 `--replace`，并会生成 `.bak.<run_id>` 备份。完成图片提升后运行
`write_image_art.py --tone-check` 与 `build_long.py --frames`，试点通过才扩展全片。
候选图片提升前可执行 `write_image_art.py --tone-check --scene-dir <候选图片目录>`，将报告
保存到该 run 的 `output/codex_jobs/<run_id>/` 下，避免覆盖正式项目的色调报告。

## API 后备工作流（DeepSeek / 万相）

1. 在 `projects/001_金钱的艺术/input/brief.md` 填写本次书目、痛点与素材要点。
2. 如需回退 API，运行 `python3 pipeline/write_long_copy.py --provider deepseek --book 《书名》 --author 作者`，
   DeepSeek 起草五段式完整脚本（含 # CARD / # QUOTE / # TABLE / # STEPS
   视觉标记与 voice：口播）到项目 `input/draft_时间戳.txt`，自动做结构校验，
   不通过会回喂模型重试；密钥自动读取项目根 `.env` 的 `DEEPSEEK_API_KEY`。
3. 人工审阅修改草稿——重点核对书中事实，定稿质量决定成片质量。
4. 确认后运行 `python3 pipeline/write_long_copy.py --accept`，
   严格校验通过后定稿到项目 `input/script.txt`（旧版自动备份 script.txt.bak）。
5. 后续出片：`python3 pipeline/build_long.py --pilot`（样段）/ 全片。

离线检查任意文案文件：`python3 pipeline/write_long_copy.py --check 文件路径`。

## 分镜与卡点画面（画面讲卡点）

主视觉为画面叙事：正文不渲染文字卡，文案由配音 + 底部逐句字幕承载；
每块口播由 AI 切成 3-5 个卡点，每个卡点一张「插画叙事」画面（人物+故事），
引擎按卡点切换画面。存在项目 `input/storyboard_narrative.json` 即自动进入
叙事模式，删除该文件即回退文字卡模式。

```bash
# 1. 生成分镜（DeepSeek，每配音块 3-5 拍 + 逐句字幕表）
python3 pipeline/write_storyboard.py
python3 pipeline/write_storyboard.py --check projects/001_金钱的艺术/input/storyboard_narrative.json
python3 pipeline/write_storyboard.py --refine    # 拆超长拍（>12s 自动拆半）

# 2. 生成卡点画面（wan2.7-image，密钥读 .env）
python3 pipeline/write_image_art.py --story                      # 全部
python3 pipeline/write_image_art.py --story --beats 00_0 02_0    # 只生成指定拍

# 3. 抽帧验收（叙事模式每拍 2 帧，含字幕版）
python3 pipeline/build_long.py --frames

# 视觉样片（跳过语音，只渲染指定块）
python3 pipeline/build_long.py --blocks 0,1,2,3,4,7,8,9,12,13 --no-tts
```

画面命名：项目 `assets/scenes/{块:02d}_{拍}.png`（如 `02_0.png`）；
阶段页用「后续内容块首张卡点画面」做背景（故事连续），缺失拍兜底为
程序化渐变；项目 `assets/art/` 为历史底图存档，渲染不再引用。

视觉参数（`build_long.py`）：主体可读、vignette=PI/7；运镜 1.0→1.08，
面部锚点 (50%,35%)，X 轴 2.5% ease-out 缓移。叙事模式无进度条、阶段徽章
或底部实条；字幕为思源 Heavy 48px，单屏 ≤15 字，底部渐变仅用于可读性。

## 画面可读性与风格控制（情绪适配 + 防雷同）

提示词分层：拍提示词 + **不变底线**（主体清楚、曝光均衡、禁止文字/水印、避免无理由的
大面积死黑）+ **项目变体**（`project.json` 的 `visual_style`）+ **负面清单**。
色彩、天气与光线必须服务当前叙事和情绪，不强制暖色或禁用冷色。

```bash
# 1. 扫描现有卡点图，输出可读性风险报告（亮度<150 / 暗部占比>25%）
python3 pipeline/write_image_art.py --tone-check

# 2. 重绘时保留该拍色彩叙事，仅提升主体可读性，再复跑 --tone-check 确认
python3 pipeline/write_image_art.py --story --force --beats 09_0 07_0
```

新项目开拍前把 `visual_style.variant` 换成未用过的变体（见
`write_image_art.py` 的 `VARIANT_STYLES`），保证叙事辨识度而不雷同。

## 最终输出分镜与插画流水线（画面讲卡点 · 无文字）

按 `docs/插画Prompts.md` 三层架构：叙事分镜先覆盖口播节奏；Codex 在本地写出
角色 ID、英文动作/情绪与 segment 计划；装配引擎再生成最终
`storyboard_output.json`（全局 2D 底模 + 叙事色彩 + 项目变体 + 角色预设 + 动作 +
景别 + 16:9）。默认图片阶段只读取这个最终分镜。

```bash
# 1. Codex 本地计划 + 装配（不调 API）
python3 pipeline/write_chibi_prompts.py --from-plan input/candidates/<run_id>/storyboard_output_plan.json \\
  --out input/candidates/<run_id>/storyboard_output.json
python3 pipeline/write_chibi_prompts.py --check    # 离线校验

# 2. 2D Q 版生图（读 input/storyboard_output.json）
python3 pipeline/write_image_art.py --chibi --beats 00_0 00_1
python3 pipeline/write_image_art.py --chibi --force   # 全量覆盖重绘
```

硬性规则：
- **画面无文字**：负面词全禁文字/数字/贴纸/气泡/图表/UI；所有文字与数据
  由引擎字幕与后期程序化叠加；
- **情绪以口播为准**：输出计划按每拍附带的口播句子确定情绪，空虚/没钱 → empty wallet/
  near-zero balance/焦虑；对比拍允许一侧积极一侧焦虑（自动矛盾检测兜底）；
- **主题一致性**：本片职场青年/都市成人财商，禁止儿童/学生等年龄身份不符形象；
- **构图安全区**：主体上 2/3、底部 1/3 留字幕安全区，无底部道具遮挡；
- **角色库**：全局 `assets/characters.json` + 项目 `input/characters.json`
  （覆盖/追加），角色定义仅外观服装标志物，不含动作情绪。

转场：块内卡点硬切（各拍 zoompan 后 concat，保留 Ken Burns）；块间 0.3s
方向型 xfade（zoomin/slide/diag/circleopen 等，不用 dissolve/fade 避免叠影）。

v2.0 合成层规范：
- **全屏画幅**：画面全屏铺满（full-bleed，禁白边/相框）；底部 15%
  半透明线性渐变遮罩（`rgba(0,0,0,0)→rgba(0,0,0,0.4)`）替代字幕实色底条；
- **字幕**：思源黑体 CN Heavy（`assets/fonts/`，失败回退 Hiragino W6）
  48px 粗体白字 + 描边 + 微投影；金额/数字→`#FFD23F`，情绪与转折词→
  `#E71D36`；单行 ≤27 字自动拆连续事件；
- **运镜**：Ken Burns 每镜头 3%-5%（`KENZOOM=0.05` 可调），单帧输入 +
  `zoompan d=nframes`（`on` 递增，避免 d=1 静止 bug）；
- **情绪主题背景**：`tone.theme_for(emotion)` 确定性映射——焦虑/困境/反思→
  冷灰蓝淡青灰，认知/启发/希望→暖杏淡金，其余→中性奶油；`--tone-check`
  主题感知（色彩服务情绪，情绪词本身不再计为风险）；
- **收尾兜底**：口播含 CTA 词（咱们开始/关注/点赞/收藏等）强制 `young_pro`，
  `none` 角色且口播含 我/你/咱们 时回退主角。

v3 精修：
- **字幕排版**：按标点切子句 → 累积 ≤15 字/屏；事件不以标点/单字开头；
  字幕事件硬切换（淡入 0.12s、enable 精确 between，无淡出重叠重影）；
- **CTA 表情**：收尾口播强制 `confident smile, determined look,
  clenching fist, ready to take action`；
- **对比双角色**：对比拍输出 `secondary_character_id`（两角色不同，
  如 frugal_girl + stressed_worker），装配为 split composition 左右两侧；
- **底部横条**：构图提示词要求 full-bleed 铺满到画面底缘，负面词禁
  bottom bar/band/strip；字幕可读性仅靠底部渐变遮罩；
- **运镜**：统一 1.0→1.08 居中缓推（`KENZOOM=0.08`）；
- **关键词音效 SFX**：`工资到账/到账/存钱→coin`、`打车/算账/计算器/账单/
  按键→calc`（ffmpeg lavfi 合成，按字符偏移定位，`adelay+amix` 混音 0.35 音量，
  缓存 `audio/tmp/sfx_*.wav`）；`SFX=0` 关闭。

v4 精修：
- **jieba 分词**：字幕按标点切子句 → jieba 分词累积 ≤15 字/屏，内置财务词组
  保护（思维框架/年薪百万/真相/金钱心理学等），固定词组不跨屏切断；jieba
  缺失回退子句按字切；
- **高亮统一明黄**：主字白色、核心词（金额/情绪/转折）统一 `#FFD23F`，
  移除珊瑚红；
- **对比二人制**：对比拍强制 `exactly two people` 左右二分屏，负面词禁
  第三人/人群/路人；
- **角色锚点**：`characters.json` 每角色带 `anchor` 特征锚点，装配时追加
  `same character as previous shots`；全局追加 `uniform bold clean line-art`
  统一描边；
- **运镜**：锚点上移 (50%,35%) 对准面部 + X 轴 2.5% 缓移 + ease-out
  （`1-(1-p)²`），切入前 0.5s 明显入场后缓推；
- **高亮词弹跳**：每屏首个高亮词独立图层，音频时刻 0.33s 正弦
  1.0→1.1→1.0 缩放弹跳；
- **reveal 音效**：`真相/揭示/撕开/原来/关键→reveal`（180→55Hz 低频冲击音）。

v5 BGM 三段式 + 智能混音：
- **素材约定**：`audio/music_seg1.{mp3,wav}`（开场 Lofi/氛围）、
  `music_seg2`（理论新古典钢琴与大提琴）、`music_seg3`（总结轻快原声）；
  缺失段自动回退 `music.wav`（保证无静音段）；
- **段边界**：每拍 `segment` 标签（hook/insight/action）由 LLM 按旁白语义
  输出，缺失时按关键词兜底（痛点→hook、作者/真相→insight、CTA/拆给你→action）；
  渲染时从已确认的 `storyboard_output.json` 合并标签到叙事分镜，
  `compute_segments` 再映射到时间轴；
- **混音**：BGM 基准 `volume=0.16`（≈-16dB）；人声段
  `sidechaincompress=threshold=0.1:ratio=3:attack=60:release=800` 避让
  6–9dB，停顿 0.8s 平滑回升；EQ `equalizer 1.5k/2.5k -2.5dB + lowpass 8k`；
  段间 0.3s afade 淡入淡出，`adelay` 定位段起点，`amix + loudnorm -14`。

## 配音（三选一）

```bash
# Piper 本地男声（默认，需提权运行）
python3 pipeline/build_long.py --blocks 0,1

# edge-tts（免费、无需密钥；默认男声 zh-CN-YunyangNeural）
TTS_SOURCE=edge python3 pipeline/build_long.py --blocks 0,1

# Azure 正式语音（.env 配 AZURE_SPEECH_KEY / AZURE_REGION / AZURE_VOICE，
# 当前主用 zh-CN-Xiaochen:DragonHDFlashLatestNeural 晓辰成熟知性女声）
TTS_SOURCE=azure python3 pipeline/build_long.py --blocks 0,1
```

配音缓存按「配置 + 文本哈希」命名存于项目 `audio/voice/`，同配置同文案
自动复用，切换音色后缓存名不同、互不混用。

## 背景乐

- 封面由独立 Agent 负责，本仓库不包含封面工具。
- 背景乐：优先 `music_seg1/2/3`，缺段回退 `music.wav`（或 mp3/m4a）；
  基准 `volume=0.16`，随后执行 ducking/EQ 与 loudnorm -14 LUFS；不放则纯人声。

## 项目切换示例

```bash
PROJECT=001 python3 pipeline/build_long.py --blocks 0,1     # 显式指定（默认即 001）
python3 pipeline/build_long.py --project 002 --pilot        # --project 覆盖环境变量
```
