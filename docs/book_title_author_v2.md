## 三层排版

| 层级 | 画布区域（1920×1080） | 表现 |
| --- | --- | --- |
| 书名铭牌 | x=470–1450，y=58–178 | 居中，浅色完整书名，低饱和金属包边、铆钉和克制的展开书页轮廓 |
| 观点主标题 | x=200–1720，y=194–410 | 金色渐变粗体、深色描边和短投影；4–16 字，优先 4–8 字单行，最多两行 |
| 解释副标题 | x=330–1590，y=426–504 | 0–14 字单行白色粗体、深色细描边，两侧短分隔线；为空时不绘制副标题或分隔线 |

三层均居中，文字按实际字形边界布局。书名必须与正式 topic 完全一致；副标题解释同一个观点，不能增加第二个卖点，不得手填作者、长段文字或新的无依据论断。长书名自动缩放或换行，越界报错。主标题不使用红色底刷或双色强调词。

## 场景规则

- 连续全画幅电影海报构图，保留动态透视、真实空间景深和冷暖照明。文字区域以自然低对比背景承接，不生成标题底板。
- 上半部 y=0–510 是文字区；生成提示要求完整头部、表情、手与关键动作位于 y=530 以下。
- 主体中下偏左，一个核心道具中右，两者以动作或清晰因果轨迹连接。辅助物件最多三件，弱化前景杂物；不做左右分栏。
- 道具、冲突和光线随本期选题变化。钱包、漩涡、绳索、玻璃裂纹均不是模板固定元素。
- 右下角 x=1632–1920、y=950–1080 只放可遮挡背景；不合成播放器时间戳。
- 画风绑定本期三张正式场景参考。品牌深蓝用于文字区遮罩，品牌前景色用于副标题；金色为主标题，低饱和金属色用于书名铭牌。
- 禁止重暗角、固定坐标光圈、无意义箭头，以及模型生成标题、文字和水印。

## 生成与合成

用户选择模板后，每期生成两个不同方案，包含 concept、hook、hook_type、subtitle、visual_metaphor、environment、character_ids。subtitle 字段必须提供，可以为空。最多使用一个正式角色。

注册表中的 scene_policy 进入密封图片提示，typography 随模板快照锁定。沿用视频 run 的图片生成方式生成无标题底图，再由本地合成器绘制书名铭牌、金色标题和白色副标题；不会将解释文案加入背景图片提示。

当前参考图用于设计对照，不自动传给正式图片任务，以免复制本期题材或文字。铭牌和文字使用确定性绘制，保留参考的层级、位置与色彩，不承诺与参考图的金属纹理逐像素一致。

## 审核与历史状态

两个候选均检查观点力度及选题依据、正片画风、情绪、品牌色、书名/钩子/副标题准确性、三层排版、表情与动作不被遮挡、无模型文字、人物与道具主次、右下角安全区，以及 320×180 缩略图可读性。

副标题在方案校验与最终验证阶段都检查长度、单行与内容一致性；两个候选均需审核记录，用户只能选择审核通过者。历史快照和发布状态不回写，模板哈希不匹配时以新的 publish ID 开始。
